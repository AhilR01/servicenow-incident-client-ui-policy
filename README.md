# ServiceNow Incident – Client Scripts & UI Policies

## Overview

This project implements UI Policies and Client Scripts on the
ServiceNow Incident table to provide dynamic field behavior,
validation, and controlled record updates.

## Project Objectives

- Create a UI Policy for Incident
- Configure the Urgency field
- Implement an onChange Client Script
- Implement an onSubmit Client Script
- Implement an onCellEdit Client Script
- Test the complete configuration
